## Build & test
```
npm install
npm run assets           # art/audio/fonts → data-URI blocks in src/page.html
npm run build            # src/page.html → index.html
npm run build:itch       # → dist/bunny-boo-itch.zip (release chrome on; upload as HTML5, viewport 960×720)
PW_EXEC=/path/to/chrome npx playwright test   # or `npm test` after `npx playwright install chromium`
```
Keep all tests green. Add a test for every behaviour change; the `window.BB` hook (bottom of the script) is the API — extend it, don't bypass it.

## Architecture (one IIFE, top to bottom)
1. **ART** – data-URI images.
2. **CONFIG** – `DEF` holds every tunable. URL params override localStorage override DEF. Add a key to `DEF` + a `[data-cfg]` input in the rail and it is automatically persisted, URL-shareable (`SHARE LINK`), exported, and shown in `COPY CONFIG`.
3. **SCENARIOS** – `SCEN` presets = partial overrides of `DEF`. `?scenario=id` applies one from the URL.
4. **RNG** – mulberry32 seeded from `CFG.seed`; every roll goes through `rng()`. Never use `Math.random()` for game logic (only for the scare-noise pixels).
5. **SESSION RECORDER** – `rec(type,data)` appends to `S.events`; `rollClaim` → `recClaim`, decisions → `recDecision`. `summary()` computes detection rate / false alarms / ms-to-decide. `exportSession()` is the JSON testers send back. **Never spread an object containing `type` into `rec()`** (it shadowed the event type once).
6. **FLOW STRIP** – `flowClaim(c)` / `flowDecide(chosen, correct, consequence)` fill the six boxes. In playtest mode truths stay hidden until the decision.
7. **DIALOG** – `say(lines, speaker, {tellAt, mood})` returns a promise. The tell fires when line `tellAt` starts typing (`tellDelayMs` offsets it). **All dialogs render in-canvas**, one 288×47 slot @ 16,125, two skins (2026-08-30): the tea party draws the friends' pink `teaBox` + `DLGPORT` portraits (vivi/mara/bunny; anyone else = hero); every other room draws the Figma Page-2 `horrorBox` + Boo's head states from `BOOPORT` — regular (`booReg`), earup (`booEar`), disappointed (`booSad`) — with pale text, and non-bunny speakers get the tea portrait purple-drained (`purpled`). **The glitch tell on Boo**: regular → earup, red-washed (`tintRed`, sprite pixels only) + 1px shiver → back when `tellMs` runs out. Tea face tells still mirror the portrait + red wash; `textglitch` shivers the words red. **Sulk**: `recDecision` sets `G.booSulk` when the player ignored the claim; Boo's next dialog rolls `mrng()` (a cosmetic side-stream of the seed — it never steals game-rng rolls) and sometimes (60%) wears `booSad`.
8. **ROOMS** – `mkRoom(name, build)`; `build(opts)` returns the room object itself (**do not copy it** — `G.room.claim` must stay live). Helpers: `rollClaim`, `wrongTrust(msg, consequence)`, `addNote`, `addBunny`. Each room sets `floor` (0–3) and `rule` (one-line designer caption).
9. **UPDATE / DRAW** – 320×180 canvas, 16:9, pixel-perfect. `drawItem` colours by `kind`: `pick` (chests/doors/cups), `clue` (wall note/mirror), `collect` (torn note), `bunny`, `npc`. Every item and door gets a label.
10. **BB hook** – `window.BB = {cfg, state, session, goto, resetRun, summary, exportSession, scenarios, applyScenario, press, hold, dialogOpen, skipDialog, teleport, roomClaim}`.

## Modes
- `mode: 'playtest'` = **PLAY** (top bar): rail hidden, log hides LIE/honest, flow strip hides truth until decision. What a tester gets.
- `mode: 'designer'` = **EDIT**: everything visible. Backtick toggles the rail independently. **Layout editor v2** (2026-08-29): click **selects** (dashed outline + red handles + the object's interact radius; a floating INSPECTOR window shows X/Y/size/reach/label/scale/flip/z-order/dup/del), drag moves, Shift+arrows nudge 1px, Del removes scenery, Ctrl/Cmd+Z undoes, SNAP = 4px grid, HITBOXES overlays every interact radius + the walkable rect, **T** flips to playtest-and-back to feel the room. The edit bar is deliberately minimal (2026-08-29, Yana's call): only ▣ INSPECTOR + ♫ MUSIC — snap/hitboxes/undo stay keyboard-only (Ctrl/Cmd+Z), deeper edits go through Claude Code. The selection's **bottom-right grip drag-resizes** (items/doors: hotspot w/h · scenery: scale). Interact radii derive from each object's own x/y (+ optional per-object `reach`), so they always travel with it; tea-party hotspots carry `follow:'<decoId>'` and move with their art. Positions persist per room in `localStorage['bb.layout2']` (deco keyed by stable `_id`, plus add/del/zorder/scale); COPY LAYOUT exports it all (incl. room music) to bake in, RESET LAYOUT forgets. Rooms declare scenery in `r.deco`; `bigChar:true` (tea party) draws the player as the `charWalk`/`charRef` sprite — `charWalk` animates only while moving, idle = static `charRef` — and adds a second interact probe at the sprite's HEAD (`probes()`), with nearest-item ranking weighted toward horizontal distance, so cups on the table are reachable from in front of it.
- **Tea party room** (2026-08-29): baked **1:1 from the friends' Figma frame** (figma.com/design/lduq59Tib9grkhvqDIZmXw "BB" / Frame 1, natively 320×180) — verified pixel-identical to the frame export. New assets: `teaWall` (wallpaper band, drawn OVER the window tops), `tableLong`, `vivi`, `mara`, `bunnySmall` (44×64 plush smooth-downscaled — premultiplied Lanczos — to its placed 21×31, matching the Figma render), `charRef` (hero holding the bunny; the idle pose) + `charWalk` (3-frame walk spritesheet from `hero_animation.gif`, 100ms/frame, moving only). Figma sources in `art/friends/figma-room/`. Gotcha: Figma metadata reports flipped layers at their transform origin, not visual bounds (visual x = x − width). The room renders **strictly 1:1** — `teaScale` is retired (stale saved values are ignored, pre-Figma tea-party layouts auto-purge on load). In floors 1–3 the player is the same `charRef` **remapped to the purple ramp** (`CFG.sprChar`, default on): the pink facade drains when she leaves the party — and she carries the bunny. **Dialogs render in-canvas game-wide** (`drawDialog`, 2026-08-29 — Figma Page 1 `text-boxes-teaparty` frames): the friends' `teaBox` (288×47 @ 16,125) + portrait sprites (`portraitVivi/Mara/Bunny/Hero` = Figma enemy1/enemy2/bunnydoll/char_ref portraits, **transparent PNGs** — node exports with the flat bg flood-filled from the borders, since the ink color also appears inside the art); the tell mirrors the portrait + red wash. The DOM dialog is removed. Legacy procedural girls (bigGirl/miniGirl) and bow/table/chairBack assets are removed.
- **Horror rooms** (2026-08-30, Figma Page 2 + `Downloads/horror-room` sprites): Boo is a real sprite in-room — `booStand` (31×58) standing (floor 1 by the door at (100,20), floor 3), the pink `plushLie` (31×32) for "sit" poses (lab, floor 2, doll room; `plushLieRed` on the in-world tell, `tintRed(booStandEar)` when standing). Floor 1 is dressed with the Figma bedroom: two `bedBR` beds (Bitglow pack via the friends' frame) + the plush on ROSE's bed, pillows = hidden hotspots on the beds, torn note under ROSE's. The player in floors 1–3 is the friends' side-walk sheet `charSide` (3 × 19×40, faces right, frame 0 idles, 100ms cycle; `p.face` keeps the last horizontal facing) — kept as-drawn per Yana (skin + bow off-palette is deliberate; the pink plush stays pink too, her call 2026-08-30; the horror bg stays the old purple wall-box, NOT the Figma frame's maroon). Boo's gif (`bunny_1.gif`) is exactly the glitch cycle frames1→2→1.
- **Music window** (EDIT bar → ♫ MUSIC, floating): global default + per-room override (inherit/musicbox/drone/silence/uploads) stored as JSON in `CFG.roomMusic`, volume (`CFG.musVol`), previews, and audio upload. **Uploads** (music + sprite slots charRef/player/bunny/doll, rail → Characters & sprites) live in IndexedDB `bb.uploads` — this browser only; baking = drop the file into `audio|art/runtime/` + `npm run assets`.
- **Title card = baked art** (2026-08-29): the friends' `bunny-boo-start-screen.png` = `art/runtime/titleCard.png` verbatim (768×432 — the art's native res; it sits on a 2px grid / logical 384×216, which does NOT fit 320×180, so any resample blurs). Rooms may declare `natW/natH`: `draw()` swaps the canvas backing store to that size and scales the transform by `natW/W`, so the card blits **pixel-for-pixel** while all 320×180-space code (fade, overlays) still covers the screen. Only the blinking PRESS SPACE (16px Silkscreen — on the art's 2px grid — `#a54a61`, drawn at native res) is code. The old title config knobs/card elements are removed. The **end card** stays config-driven: `titleFont/titleColor/endTagline` (rail → End card), with `endTagline` still a clickable card element in EDIT. SHARE LINK / COPY CONFIG carry everything.
- `release: true` (`?release=1`, default in the itch build): playtest + no topbar/mode pill/backtick — only the game, HUD, sound button, and short help line. Never persisted to localStorage.
- **◉ PROD** (top bar, or **T** from EDIT): session-only *production preview* — the exact release view, plus a faded EXIT PLAYER VIEW chip (bottom-right) and T to return, neither of which exists in the real itch build. `BB.prod.{enter,exit,on}`.
- Boot goes to the **title card** (Space starts); the ending goes to an **end card** (stats, Space → title). `?room=` / `skipIntro` skip both, so test URLs are unchanged.

## Conventions
- Palette is locked (5 purples + red reserved for petals/tells/blood/candle). One sanctioned exception (2026-08-29): the friends' **pink ramp lives only in the tea party room, the in-canvas dialog box (game-wide — Yana's call, 2026-08-29), and title/end text** — pink is the warm facade, purple is the house's truth. Floor 1–3 *scenery* stays pink-free; the dialog box is the facade speaking.
- Audio: **five** embedded m4a loops — musicbox, drone + `comeplay`/`ossuary`/`deepnoise` (Kevin MacLeod, incompetech.com, CC-BY — credit whichever ships). Pick per room in the ♫ MUSIC window; `CFG.music` global. SFX via the `sfx(name)` WebAudio synth, incl. a soft per-letter typing `blip` in dialogs. **No tell SFX ever** — the tell must stay visual-only, that's the design question the game asks.
- Combat is a bounded module behind `CFG.combat` (default off). If it isn't fun by Friday it is cut; the doll room already has its "run to the door" fallback.
- Don't add features to the testbed that the Unity build won't have. It exists to answer the GDD's open questions, not to become the game.
